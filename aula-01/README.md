\# Aula 01 — Fundamentos de Git e Docker



\## O que aprendi



\### Git



\- Aprendi a inicializar um repositório utilizando `git init`.

\- Aprendi a trabalhar com branches para separar o desenvolvimento de uma funcionalidade da branch principal.

\- Pratiquei o uso de commits com mensagens descritivas seguindo o padrão de Conventional Commits.

\- Aprendi a adicionar arquivos ao controle de versão utilizando `git add` e registrar alterações com `git commit`.

\- Entendi a importância de manter um histórico organizado para acompanhar a evolução do projeto.



\### Docker



\- Aprendi a criar um `Dockerfile` para transformar uma aplicação em uma imagem Docker.

\- Entendi a função do `WORKDIR`, `COPY`, `RUN`, `EXPOSE` e `CMD` dentro de um Dockerfile.

\- Aprendi que o `.dockerignore` evita enviar arquivos desnecessários, como `node\_modules`, para o contexto de construção da imagem.

\- Pratiquei a construção de imagens utilizando `docker build`.

\- Entendi como executar uma aplicação dentro de um container utilizando `docker run`.
